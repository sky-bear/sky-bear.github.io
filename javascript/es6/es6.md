# ES6

所谓的 ES6，就是 ECMAScript 6 的简称，也就是 ECMAScript 第 6 版，它的正式发布是在 2015 年 6 月， 随后更名为 ECMAScript 2015。
而 2008 年发布的 ECMAScript 3.1 被称为 ES5。

## ECMAScript 和 JavaScript 的关系

ECMAScript 和 JavaScript 的关系是，前者是后者的规格，后者是前者的一种实现（另外的 ECMAScript 方言还有 JScript 和 ActionScript）。
