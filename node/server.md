## node 框架

### express

### koa

中间件的 next 实际上指的是下一个 use 的函数， 基于函数执行占， 所以 next 之前的代码按照顺序执行，next 之后的代码按照逆序执行

1. 中间件（Middleware）： Koa 的应用是由一系列中间件组成的。中间件是一个包含 async 函数的模块，它可以执行一些操作，然后通过 await next() 来调用下一个中间件。中间件按照声明的顺序依次执行。
2. Context（上下文）： Koa 的中间件接收一个 context 对象，它包含了对请求和响应的引用，以及一些有用的工具方法。context 对象具有更多的属性和方法，使得处理请求和响应更加方便。
3. 异步流程： Koa 鼓励使用 async/await 来处理异步操作，使得代码更加清晰和易于理解。中间件可以使用 await 关键字等待异步操作完成，而不必使用回调函数。
4. 洋葱模型： Koa 中间件的执行顺序形成了一种洋葱模型，请求进入中间件栈的一端，然后按照顺序一个个经过中间件，最后从另一端出去。每个中间件在请求进入和响应离开时都有机会执行操作。
5. 上下文扩展： 开发者可以通过向 context 对象添加属性和方法来扩展其功能，以满足特定应用的需求。这为自定义中间件和插件提供了更大的灵活性。
6. 错误处理： Koa 提供了一种处理错误的机制，通过 try...catch 来捕获错误。当一个中间件发生错误时，可以使用 try...catch 来捕获错误，并通过 context.throw() 抛出一个 HTTP 错误。

### 区别

- 架构风格
  - Express： 功能丰富型框架
  - Koa： 轻量级框架
- 异步处理方式
  - Express： 回调函数
  - Koa： Generator + co
  - Koa2： async/await
- 中间件机制
  - Express： 中间件函数
  - Koa： 中间件类
- 路由机制
  - Express： 内置路由
  - Koa： koa-router
