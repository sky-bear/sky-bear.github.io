# 前端负责人核心职责

## 技术管理
### 前端技术规范体系
1. **代码规范**
   - ESLint规则配置（Airbnb/Standard）
   - Prettier代码格式化标准
   - 命名规范（组件/变量/文件）
   - 注释规范（JSDoc标准）

2. **工程规范**  
   - 项目目录结构标准
   - Git工作流（Git Flow）
   - CI/CD流程规范
   - 依赖管理规范

3. **组件开发规范**
   - 组件设计原则（单一职责）
   - Props/Emits类型定义
   - 状态管理规范（Pinia/Vuex）
   - 单元测试覆盖率标准

4. **性能规范**
   - 资源加载优化标准
   - 代码分割策略
   - 缓存策略（HTTP缓存/Service Worker）
   - 监控指标阈值

5. **安全规范**
   - XSS防护方案
   - CSRF防护措施
   - CSP内容安全策略
   - 敏感数据处理规范

- 主导技术选型和技术栈升级（如React/Vue版本升级）
### Code Review检查清单
1. **代码质量**
   - 是否符合编码规范（ESLint/Prettier）
   - 是否有重复代码或冗余逻辑
   - 错误处理是否完备（try-catch/边界条件）
   - 代码可读性和可维护性

2. **功能实现**  
   - 是否完全实现需求功能
   - 业务逻辑是否正确
   - 是否有未处理的边缘情况
   - 与现有功能是否兼容

3. **性能考量**
   - 是否存在内存泄漏风险
   - 是否有不必要的重渲染
   - 大数据量处理是否优化
   - 网络请求是否合理（合并/缓存）

4. **安全防护**
   - 用户输入是否做XSS过滤
   - 敏感信息是否加密处理
   - API权限控制是否恰当
   - 日志是否包含敏感信息

5. **测试覆盖**
   - 单元测试是否覆盖核心逻辑
   - 测试用例是否包含边界条件
   - Mock数据是否真实可靠
   - 自动化测试是否可通过

- 建立代码Review机制和质量标准
- 性能优化方案制定和实施

## 团队建设
- 制定团队成员成长路径和培训计划
- 组织技术分享和知识沉淀（每周技术分享会）
- 新人onboarding流程建设和指导
- 团队技术氛围营造

## 项目管理
- 参与需求评审和技术可行性评估
- 制定合理的开发计划和排期
- 风险识别和应急预案制定
- 质量保障流程建设（单元测试、自动化测试）

## 业务赋能
- 深入理解产品业务逻辑和用户需求
- 技术驱动产品创新和体验优化
- 建立数据埋点和分析体系
- 跨部门协作沟通（与产品、设计、后端团队）

## 日常工作
- 任务分配和优先级管理
- 技术难题攻关和决策
- 团队绩效评估和反馈
- 技术招聘和面试
